# grade_level 정의 원칙

`grade_level`은 학생, 수강과정, 문제지에 공통으로 사용하는 학년 코드 필드다. 값 체계는 공통으로 `E1~E6, M1~M3, H1~H3`를 사용한다. 다만 이 필드는 공통 코드 체계를 위한 것이지, 서로를 자동 연결하거나 제한하는 기준으로 쓰지 않는다. 즉 같은 `grade_level`이라고 해서 학생-강좌, 학생-문제지가 자동 매칭된다고 해석하지 않는다. 선행, 심화, 복습, 월반 수강이 가능하므로 실제 연결은 별도의 관계 데이터(`student_courses`, `assignments` 등)로 관리한다.

### students.grade_level
`students.grade_level`은 학생의 현재 학년을 뜻한다. 예: 현재 중학교 1학년 학생이면 `M1`. 이 값은 학생 현황, 학생 목록 필터, 학생 통계, 기본 조회 기준에 사용한다.

### courses.grade_level
`courses.grade_level`은 해당 수강과정이 기본적으로 어느 학년을 대상으로 설계된 과정인지를 뜻한다. 예: `중3 물화반`이면 `M3`. 이 값은 과정 분류, 과정 목록 필터, 과정 검색, 운영 관리 기준에 사용한다.

### test_sets.grade_level
`test_sets.grade_level`은 해당 문제지/시험지가 기본적으로 어느 학년 수준 또는 어느 학년용으로 분류되는지를 뜻한다. 예: 중3 화학 파트 문제지이면 `M3`. 이 값은 문제지 분류, 검색, 필터, 추천 기준에 사용한다.
