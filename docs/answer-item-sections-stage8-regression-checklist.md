# 답안 입력폼 문항 섹션 기능 8단계 회귀검증

이 문서는 1~7단계 배포 후 실제 브라우저에서 수행하는 최종 회귀검증
체크리스트다. DB 계약은
`db/audit_answer_item_sections_stage8_final_regression.sql`로 별도 확인한다.

## 준비

- 테스트용 강좌와 학생을 사용한다.
- 제목 없는 기존 시험지 1개와 `Level 1`·`Level 2`가 있는 시험지 1개를 준비한다.
- 섹션 시험지는 서로 다른 섹션에 같은 표시번호(예: 각각 `1번`, `2번`)가 있어야 한다.
- 브라우저 캐시 영향을 피하려면 배포 후 `Ctrl+F5`로 새로고침한다.
- 실패 시 시험 제목, 학생, assignment ID, attempt ID, 단계와 화면 캡처를 기록한다.

## 12개 시나리오

| ID | 시나리오 | 수행 방법 | 통과 기준 | 결과 |
| --- | --- | --- | --- | --- |
| R01 | 기존 CSV 호환 | 섹션 제목이 없는 기존 CSV를 검증하고 등록한다. | 기존 형식 그대로 등록되고 문항 수·정답·선택지 수가 변하지 않는다. | ☐ |
| R02 | 섹션 CSV 등록 | `Level 1`, `Level 2` 제목 행과 마지막 빈 줄이 있는 CSV를 등록한다. | 제목 행은 문항 수에서 제외되고 두 섹션과 실제 문항만 저장된다. | ☐ |
| R03 | 잘못된 섹션 CSV 차단 | 섹션 첫 문항을 `2`로 시작하거나 같은 섹션에 표시번호를 중복시킨다. | 등록 전에 명확한 행 번호와 원인으로 차단된다. | ☐ |
| R04 | 제목 없는 시험지 표시 | 기존 시험지를 학생 화면에서 연다. | 기존 레이아웃을 유지하고 문항 라벨은 `13번` 형식이다. | ☐ |
| R05 | 섹션 시험지 PC 표시 | 2개 섹션 시험지를 PC 폭에서 연다. | 섹션 제목이 전체 폭을 사용하고 각 섹션 문항은 2열로 표시된다. | ☐ |
| R06 | 섹션 시험지 모바일 표시 | 같은 시험지를 모바일 폭에서 연다. | 섹션·문항 순서가 유지되고 1열로 자연스럽게 접힌다. | ☐ |
| R07 | 미입력 안내 라벨 | 서로 다른 섹션의 문항을 미입력한 채 제출한다. | 안내가 `Level 1 - 2번`, `Level 2 - 2번`처럼 모호하지 않게 표시된다. | ☐ |
| R08 | 1차 진행 중 복원 | 일부 답안을 선택하고 제출하지 않은 채 새로고침한다. | 선택 답안, 섹션, 표시번호와 순서가 그대로 복원된다. | ☐ |
| R09 | 1차 만점 완료 | 모든 답을 맞게 입력하고 1차 제출한다. | 즉시 완료되며 점수·정답 수·상태가 기존 규칙과 일치한다. | ☐ |
| R10 | 섹션별 동일 번호 채점 | 두 섹션의 같은 표시번호 중 하나만 틀리게 1차 제출한다. | 내부 `item_no`가 충돌하지 않고 틀린 문항 하나만 정확한 섹션 라벨로 2차에 나온다. | ☐ |
| R11 | 2차 복원과 종료 분기 | 2차 화면을 새로고침한 뒤 한 번은 모두 정정하고, 별도 응시에서는 오답을 남긴다. | 복원 후 같은 문항이 보이며 각각 `completed`와 `needs_review`로 정확히 전이된다. | ☐ |
| R12 | 교사용 오답 툴팁 | 교사 관리 화면에서 제목 없는 시험지와 섹션 시험지의 1·2차 점수에 마우스를 올린다. | `13번` 또는 `Level 2 - 3번`으로 표시되고 라운드별·표시순서대로 나열된다. | ☐ |
