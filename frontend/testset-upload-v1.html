문제지 등록 페이지 v2

실제 등록용 버전입니다. 현재 DB 구조에 맞춰 등록하며, 교육과정/단원코드/소스 정보는 제목과 기본 메타값에도 반영되도록 구성했습니다.

실작동 버전
Supabase 연결 설정
브라우저 localStorage에 저장됩니다. 현재 페이지는 auto_grading 스키마의 create_test_set_from_json RPC를 호출합니다.

문제지 기본 정보

학년 코드는 위에서 선택하고, 여기에는 3자리 숫자만 입력합니다.

단원 정보

1) 단원코드 3자리(예: 112)를 직접 입력하면 아래 대단원/중단원/소단원이 맞춰집니다. 2) 반대로 아래 대단원 → 중단원 → 소단원을 선택하면 위 단원코드가 자동으로 채워집니다. 현재는 범용 숫자 체계로 동작하며, 소단원명은 일부 샘플 매핑만 포함되어 있습니다.

문항 CSV 업로드

CSV 파일 업로드선택한 CSV를 파싱한 뒤 create_test_set_from_json RPC로 실제 등록합니다.
필수 컬럼: item_no
필수 컬럼: answer_key
선택 컬럼: choice_count
선택 컬럼: topic_tag
선택 컬럼: note

운영 메모

          

            현재 DB의 create_test_set_from_json RPC는 curriculum_version,
            nano_unit 전용 컬럼을 아직 직접 받지 않습니다. 그래서 이 페이지는
            교육과정/단원코드/소스 정보를 제목에도 함께 반영해 당장 운영에
            필요한 식별성을 유지하도록 구성했습니다. 이후 DB 컬럼이 추가되면
            해당 부분만 분리 저장하면 됩니다.
