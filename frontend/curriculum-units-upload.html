curriculum_units 업로드

업로드

DB에 저장되는 `subject` 식별자입니다. 기존 문제지 등록 페이지와 정확히 같은 값을 넣어야 하며, 중등 과학은 `중1과학`처럼 공백 없이 입력합니다.
1) 빈칸은 바로 위의 대단원/중단원 값을 이어받습니다.
2) 소단원 행 1개는 `100 / 110 / 111` 식 계층 row를 보장합니다.
3) 예: `5 / 생식과 유전`, `2 / 유전`, `1 / 멘델의 유전 원리와 중간 유전` 이면 `500`, `520`, `521`이 산출됩니다.
원본 행 해석 레벨 대단원 중단원 소단원 산출 코드
CSV를 선택하고 `CSV 해석 미리보기`를 눌러 주세요.
