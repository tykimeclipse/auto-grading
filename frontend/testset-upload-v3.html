문제지 등록 페이지 v2

실제 등록용 버전입니다. 현재 DB 구조에 맞춰 등록하며, 교육과정/단원코드/소스 정보는 제목과 기본 메타값에도 반영되도록 구성했습니다.

실작동 버전

문제지 기본 정보

학년 코드는 위에서 선택하고, 여기에는 curriculum_units의 unit_code 3자리만 입력합니다. 대단원은 `100`, 중단원은 `110`, 소단원은 `111`처럼 뒤 자리를 0으로 채워 계층을 표현합니다.
검색 결과가 여러 건일 때 ID를 복사해 여기에 붙여넣으면 정확히 1건만 조회됩니다.

단원 정보

DB 연결 후 curriculum_units를 불러오면 현재 선택한 교육과정 / 학년 / 과목 조합에 맞는 단원 목록이 여기에 반영됩니다. 중단원과 소단원 드롭다운에는 `0. 선택없음`이 포함되어 대단원/중단원/소단원 범위를 모두 선택할 수 있습니다.

문항 CSV 업로드

CSV 파일 업로드선택한 CSV를 파싱한 뒤 create_test_set_from_json RPC로 실제 등록합니다.
필수 컬럼: item_no
필수 컬럼: answer_key
선택 컬럼: choice_count
선택 컬럼: topic_tag
선택 컬럼: note

운영 메모

현재 페이지는 subject 값을 curriculum_units.subject와 정확히 일치시키고, 단원명은 curriculum_units 원본에서 조회해 사용합니다. 등록 호출에서는 source_type(내부 enum)과 source_category(화면 라벨)를 분리해서 전송합니다.
